Every name, tier, ID, number, error string, date and link on this page is made up to show the layout of a weekly report. Quotes are omitted from this public sample. In a real report every factual sentence links to the public post it rests on; a few citation markers such as [E14] are shown below, with an excerpt of the evidence appendix at the end.

How to read this

  • Priority (issues) and Demand (requests) run from 0 to 100, printed to one decimal. The Monday email, the one-pager, alerts and the teaser print the same stored score for the same week.
  • Reporters are unique people, not posts.
  • Badges show whether a sentence is Reported, Aggregated, Inferred or Secondhand.
  • S1 to S5 is severity, from safety or security (S1) to cosmetic (S5).
  • The verifier tally at the end shows what was removed or rewritten before release.
